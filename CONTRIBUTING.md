# Contribution Guidelines

Thank you for helping curate the Awesome Technocore list!

## Submission Criteria
1. The project must be directly related to Technocore, Flop Labs, or Ed25519 decentralized agent identities.
2. The repository or resource must be publicly accessible and functional.
3. Use clear, concise descriptions in professional English without promotional fluff or emojis.

## How to Submit
1. Fork this repository.
2. Add your link in alphabetical order under the most appropriate category in `README.md`.
3. Open a Pull Request with a clear title and brief description of the tool.
